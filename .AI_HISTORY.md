### Bash Script Compliance - Added `true` at End
- Added `true` as final line to all OPP step-registry command scripts
- **Why:** MPEX Integrity Engineering Best Practices requirement
- **Rule:** All bash scripts must end with `true` or explicit exit statement
- **Impact:** Without it, script exit code depends on last command, can cause false failures
- **Files:** 11 scripts in `ci-operator/step-registry/interop-tests/opp-*/*-commands.sh`
