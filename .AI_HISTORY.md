### Fix spoke-upgrade stuck in Partial state due to spec.overrides (job #2096621500084785152)

This causes CVO to report `Upgradeable=False` with "Disabling ownership via cluster version overrides prevents upgrades between minor or major versions." The CVO keeps state as `Partial` (never `Completed`) when overrides are present during a minor upgrade.
- `PatchAdminAcksForUpgrade` only handled `ack-*` keys; the overrides message matched neither branch and the script fell through silently, proceeding to apply the upgrade ManifestWork against a non-Upgradeable cluster.
- Fix: added `elif grep -q "cluster version overrides"` branch to `PatchAdminAcksForUpgrade` in `acm-interop-p2p-spoke-upgrade-commands.sh` that clears `spec.overrides` (via `patch --type merge -p '{"spec":{"overrides":null}}'`) before the upgrade proceeds. Overrides are safe to remove at this point — they were set only during provisioning to bypass Sigstore and are no longer needed once the spoke is registered.
