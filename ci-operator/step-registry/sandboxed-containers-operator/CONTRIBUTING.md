# Contributing to the OSC Step Registry

Start with the [OSC CI contribution guide](../../config/openshift/sandboxed-containers-operator/CONTRIBUTING.md)
for the intended workflow, its step graph, and guidance on finding reusable steps.

This directory defines reusable steps, chains, and workflows. See the
[step-registry README](README.md) for OSC workflow details. Job definitions and
pipeline configuration live in the linked `ci-operator/config` directory.
